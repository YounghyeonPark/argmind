# The four captured screens

What UI Automation read off four real windows on the author's machine: Character Map, System
Information, Paint and a Chrome Remote Desktop session. `choosing`, `saying`, `talking`, `judging`
and the rest read them from here, and only the `.json` files are read.

**Redacted on 2026-11-17, before the repository was made public: names only.** The machine's
name became `LAPTOP-EXAMPLE`, the Windows account `user`, and the remote machine `REMOTE-PC` (so
this file's name changed with it). Nothing else in any screen moved: not a rectangle, not a role,
not the order. The same three replacements were made everywhere a recorded answer or a finding
quoted those names.

**That moved the screen fingerprint from `5020f7` to `9d54a1`**, and the prompt fingerprint
`r322a4c` did not move. Every result file tagged `s5020f7` was taken against the names before the
redaction, so a run tagged `s9d54a1` is a different measurement by construction. The model was
shown other tokens, and nobody has measured whether that changes a choice.
